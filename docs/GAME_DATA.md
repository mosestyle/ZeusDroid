# Game data: what the port needs and where it comes from

The APK and this repository contain **no** Zeus/Poseidon content. Two user-provided
inputs are required:

1. **Your own Zeus: Master of Olympus + Poseidon installation** (tested: GOG edition,
   English, `Zeus.exe` "Version 1.11", see BINARY_COMPATIBILITY.md).
2. **The eZeus 0.8.2-beta data pack** (`eZeus-0.8.2-beta.zip` from
   https://github.com/MaurycyLiebner/eZeus/releases/tag/0.8.2-beta). It holds eZeus' own
   pre-scaled PNG atlases (`interface.e`, `i15.e`, `i30.e`; optional `i45.e`/`i60.e` from
   `i45.zip`/`i60.zip`), `Fonts/Zeus.ttf`, `Text/language.txt` and two eZeus-made adventures.
   The table in `engine/esplitbinary.h` (name → file/offset/size) has not changed since tag
   `0.8.2-beta`, so these packs match the pinned engine revision.

## Text conversion

`Zeus_Text.eng` and `Zeus_MM.eng` use the Impressions text/message formats. eZeus releases
expect XML made with `engconverter-0.5.exe` (Windows, UPX-packed Qt4). It was identified as
the MIT-licensed *citybuilding-tools* engconverter (Bianca van Schaik,
https://github.com/bvschaik/citybuilding-tools, commit `ea749c6e`). Its format logic was
reimplemented twice:

* `tools/assets/eng_to_xml.py` – desktop staging tool;
* `engine/platform/eengconverter.cpp` – runs inside the game at first launch if the XML is
  missing, so phones only need the raw `.eng` files.

Encoding: Windows-1252 → UTF-8 (the converter's default "Windows-1252" choice). Escaping
follows Qt's `QXmlStreamWriter` (`< > & "`), which eZeus relies on (it un-escapes `&quot;`
in `characters/esoldierbanner.cpp`). Verification: both converters produce byte-identical
XML for the user's files (sha256 prefixes `577ec188…` for Zeus_Text.xml, `cb5e23ef…` for
Zeus_MM.xml), including the ARM64 build of the native converter under qemu.

## Layout on disk

```
<root>/ZeusPoseidon/            ← game root (eGameDir::path)
  DATA/ Audio/ Model/ Adventures/ Zeus_Text.eng Zeus_MM.eng zeus.ico
  eZeus/                        ← eZeus files (Bin/../)
    interface.e i15.e i30.e [i45.e i60.e] Fonts/ Text/ Adventures/
    Zeus_Text.xml Zeus_MM.xml   ← generated
    settings.txt numbers.txt    ← written by the engine
    Save/<leader>/              ← saves (never touched by the importer)
    Bin/                        ← "binary directory" (EZEUS_BIN_DIR); empty on Android
```

* Android: `<root>` = `/storage/emulated/0/Android/data/org.zeusport.game/files`
  (`Context.getExternalFilesDir(null)`, app-owned, no storage permission, removed on uninstall).
* Desktop development: `local-assets/` (git-ignored), created by
  `tools/assets/stage_dev_assets.py` (symlinks by default, `--copy` for a portable folder).

## Getting the files onto a phone

1. On the PC, optionally unzip `eZeus-0.8.2-beta.zip` into the `Zeus and Poseidon` folder
   (as the eZeus README instructs for Windows) – the importer then picks up both at once.
2. Copy the whole `Zeus and Poseidon` folder to the phone (USB file transfer, SD card, or a
   cloud drive that appears in Android's file picker). About 0.85 GB without movies.
3. Open the app → **Import game folder…** → select that folder. Then, if needed,
   **Import eZeus data pack (.zip)…** (you can also download the zip directly on the phone).
4. The import is resumable: unchanged files (same size) are skipped, partial files are written
   as `*.part` and renamed only when complete. Re-importing never deletes saves.

## Validation

```
python3 tools/assets/validate_game_data.py check "<Zeus and Poseidon>" --ezeus "<…>/eZeus"
```
reports missing required files, size mismatches, digest differences (other editions), and
case mismatches (Linux is case-sensitive; Windows and Android shared storage are not). On
Android the same required set is checked by `ImportRules.validate()` before the game starts.
